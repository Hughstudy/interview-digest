## 分章详解

### 第一章：开场与一个月快讯（00:00 - 03:51）
泓君先用一段独白交代背景：GPT-6 Astra 发布才一个多月，但对 Agent、机器人和 AI for Science 三个领域来说，可能是历次模型更新里冲击最大的一次，不少人称之为"机器人领域的 GPT 时刻"。她快速盘点了一个月内的关键进展，这些名字后文都会反复出现，值得先记住：

- **Agent 端**：Astra 发布 5 天后 Meta 上线个人 agent「Meta Muse」，给每个用户一台云端虚拟电脑，两周冲到美国 App Store 榜首；对手 Instinct 估值一个月内从 25 亿美元涨到 100 亿美元；xAI 的 Grok Bot 开放企业部署；新模型 Jev（母公司 TypeSafe）只给选项打概率、不写字不推理，自称"系统1"模型，发布 24 天融资 8.7 亿美元、估值 75 亿美元。
- **AI 制药端**：9 月底 Claude 仅用 21 小时自己找到一个叫 ART 的新酶系统，结构酷似 CRISPR，被怀疑是新的基因编辑机制，导致一批基因编辑公司股价应声下跌；10 月初扎克伯格夫妇的 Biohub 把"虚拟细胞计划"扩大到 18 亿美元，谷歌 DeepMind、Meta、Isomorphic Labs、美国能源部、NIH 一起出钱出数据，目标是让药物还没进实验室就能在电脑里看细胞反应——本质上是在解决 AI 制药的数据问题。

这段快讯的作用是给全期节目立好坐标轴：后面三章（Agent、机器人、制药）分别对应这三条线，嘉宾的所有判断都发生在这些事件之后。

### 第二章：初体验：Astra 惊艳在哪（03:51 - 08:20）
许华哲（机器人方向）的团队给 Astra 接上各种机器人本体做了大量实测。他总结出两个"过去的模型不具备"的能力：

第一是**把反思变成动作**。给 Astra 一个新机器人本体，它会自己发现"这个机器人的运动空间是这样的"，撞到桌子会说"这桌子蛮高，我是不是该把手抬高点"——即 CoT（思维链）式的自我反思第一次能落地成实际动作调整。第二是**自我迭代**：网上著名的机械臂画金门大桥 demo，第一遍画得很差，但画完它会想"怎么画更好"，几轮迭代后非常逼真。他们自己复现的是更高难度的插花：花的茎被劈开两半、末端分叉，正常塞不进瓶口，Astra 能理解"因为分叉了，所以我要捏住分叉处捏窄一点再塞"。许华哲判断这本质上是 3D 理解能力——尚不涉及动态物理，但已能覆盖大量非动态操作任务。第三个惊艳点是 **Real-to-Sim**：过去把真实环境搬进仿真要拍大量照片加人工标定，现在给 Astra 几张图片就能快速复现整个实验室环境，直接拿去训机器人。

Bill（模型公司 Pokee.ai）的体感则冷静得多：Astra 强调的后训练/迭代能力"试下来并没有那么惊艳"，真正的提升在长程任务的稳定性和上下文认知、幻觉率下降——但跑一晚上 24 小时的长任务幻觉仍会发生，没有根本解决；速度也偏慢。他朋友测前端和设计任务，发现审美有大幅提升，猜测训练时对设计方向做了特殊处理。两位嘉宾一热一冷的对比，为第三章"到底算不算大节点"的分歧埋下伏笔。

### 第三章：是不是"大节点"：三种视角（08:20 - 13:18）
泓君问了一个全场最尖锐的问题：Astra 对行业的影响，比得上当年 Opus 4.6 对 Coding 的范式转变吗？

Bill 的回答是否定的，且给出了清晰的判断框架：4.5→4.6 那次是"范式式转变"——工具调用几乎不出错、长程 coding 可以自主进行，是从"不能"到"能"；而 Astra 只是"比原来更长的任务能做得更长、幻觉更低、审美更好"，属于量变，"没有解决一个以前完全解决不了的问题"。这个"能不能做以前做不了的事"的标准，是全期节目反复使用的隐性尺子。

王晟（AI for Science）的回答则是明确的"是大节点"。他的证据不是 benchmark，而是行为：整个组已经从 Claude 系列整体切换到 GPT-6 Astra 跑内部生物医学任务。两个杀手级用途：一是 **Computer Use（计算机操作）**——生物医学领域有大量多年前编写的"领域默认软件"，界面烂、术语多、跨领域学者用不动；Astra 能按简单 prompt 直接操作好这些软件，因为他判断 Astra 把这些软件的网上教程、用户日志、反馈全部以文字形式学进去了，是"真的理解怎么用"。发布时演示的 MultiQC（一个常用网页工具）demo 在圈内"出圈"了。二是**长程任务**：生物医学任务一跑就是 8-24 小时，Astra 慢但稳。他的工作流变成了"白天用快模型，晚上让 Astra 设计长程 pipeline 跑一整晚"——慢反而让人放心。这一章确立了本期最重要的结构性事实：同一个模型发布，Coding 视角看是量变，科学视角看是质变，分歧的根源在于各领域"以前卡在哪"。

### 第四章：Computer Use 回潮与 Meta Muse 困局（13:18 - 22:20）
这一章讨论一个行业级疑问：前两年大家都说未来是"API + Agent native"，为什么 Computer Use（模型看屏幕、点鼠标打字，像人一样操作电脑，无需接口和密码）又火了？

Bill 的解释是**利益结构逼的**：大量第三方 APP——Amazon、购物、旅行类——根本不愿意开放 API。于是 Instinct、Meta Muse 背后都接了浏览器。但这重演了 Manus 的老路：Manus 最早做 browser use，被各家网站封杀后被迫转向白领工作效率场景（Claude Code、ChatGPT Work 最后也都偏到这个方向），核心原因就是"一开始能做的东西很快被巨头 block 掉"。现在亚马逊已经屏蔽了 Meta Muse。

Bill 给出的破局判断是本期最有商业价值的洞察之一：**浏览器操作从云端搬到本地**。云端 browser use 要靠商用 IP 或代理伪装成消费者，商家可以随时封锁；但如果操作发生在用户自己的设备上（用他公司做的 30B 级小模型跑在 AI box / AI PC 里），用的就是用户自己的 IP——"他不可能把你电脑上的浏览器屏蔽掉，那你自己也别上亚马逊了"。由此他推出更根本的一层：**身份（Identity）才是这波 toC agent 的关键**。商家抗拒的不是 agent，而是"一个用户带 20 个 agent 来刷流量、比价、搅乱流量入口"；如果硬件能证明"这个 agent 就代表这个用户本人"，商家就愿意放行。所以他的结论是：这波 consumer agent 最终会落到软硬件结合，模型、软件、硬件三方合作才能破局。

成本侧同样残酷：Meta Muse 每人免费送 1 亿 token，按成本估算约等于每个用户每周 100 美元的免费额度——"就纯烧钱嘛"。Bill 还分享了 RL 训练的实战细节：他们原来租虚拟 sandbox 服务太贵，最后直接租大 CPU box 自建；有一次大规模 rollout 时 CPU 价格居然和 GPU 一样贵。Meta Muse 后台据传官方是 Muse Spark，但 X 上有人扒出调用了 OpenAI 的场景，怀疑存在路由；Bill 算账：如果 10% 流量路由到 Astra 级别模型，成本就不是每用户 100 美元而是 200 美元/月，"这获客成本有点离谱"。他自己烧过一次 Claude 20x 套餐后花 100 美元买额度，仅仅两三个来回的 agent flow 就用完了——这就是为什么他赌 60-70% 的 token 未来应该在本地/私有算力产生。
### 第五章：谁在真正烧 token（22:20 - 27:45）
承接上一章的成本话题，泓君抛出一个从前沿模型研究员那里听来的反直觉观点：现在 toC 消费级 agent 的 token 用量"其实花不了多少钱"（推理成本在降），真正烧钱的无底洞是 **AI for Science**——那些未被解决、未被定义的科学问题。这才是 OpenAI、Anthropic、DeepMind 几家真正在竞争的核心领域。

数字很硬：OpenAI 解纳维-斯托克斯方程那一个问题，它的 agent 发了约 270 万条信息、消耗约 1300 亿输出 token，第三方按零售价估算约 2200 万美元。一个数学问题烧掉两千万美元级的推理——这就是"前沿 lab 视角"和"普通人视角"的差距：普通人感知不到 Astra 和上代模型的区别，但对前沿科学家来说能力提升感知巨大。逻辑也直白：如果 AI 真能制药、能解决疾病，那个利润量级远超卖订阅。

这章在全片论证里的位置：它解释了为什么三家嘉宾从不同领域被请到一起——模型能力的天花板由最烧钱的科学计算定义，而这些能力迟早"溢出"到 Agent 和机器人。泓君还点出一个梯队现象：走在前面的公司什么模型都能随便用，走在后面的传统企业（法律、医疗）还在 Microsoft Copilot 的泥潭里挣扎，连 Codex 和 Claude Code 都不能自由用——行业分化极大，Grok Bot 这种新东西短期内接不进传统 B 端工作流。

### 第六章：代际跃迁 vs 小模型追赶（27:45 - 31:40）
Bill 问两位教授一个内行问题：从 Opus 4.5→4.6 的提升，对比 4.8→Fable 或 5.6→Astra 的提升，量级可比吗？两位的回答再次分化，且各自带机制解释。

王晟：AI for Science 能力确实大幅提升，但**提升全部来自通用 coding / 查文献 / 长程任务**，生物医学知识 benchmark 上 Astra 并没有提升。更糟的是使用体验在变差：模型越强，对生物医学任务防范越严，动辄拒绝回答（refuse to answer），他们内部实际主力用 Kimi K3 或 Muse Spark 1.3，用 Astra 时得用特殊措辞说服它"我只是在设计 benchmark，不是做危险任务"。他还抛出一个更深的观点：**现在的生物医学 benchmark 本身定义得就不好**——都是给定数据集、预测明确问题的 Kaggle 式数据科学比赛，退化成 MLE-bench（机器学习工程基准）里的 ML 问题，和真实的制药发现差距巨大，所以"大家追赶的方向可能都不是完全正确的"。

许华哲：对机器人来说 Astra 是**飞跃式（定性）的**——过去从 Opus 4.5、4.6 到 Fable 的所有升级，在机器人测试上"原来不能做现在仍然不能做"，定性没变化；Astra 是第一次定性变化，RoboDojo 等几个公认机器人（尤其仿真）benchmark 直接被屠榜拿第一。但他同时给出约束：机器人任务有时间要求，需要高动态快速响应（比如抖毛巾），Astra 太慢做不到——它知道该快动一下，但只能写代码来实现，直出动作不行。所以长期"一定需要一个小的、能力跟 Astra 相当的模型"。

这章是全片的枢轴：同一个"代际"概念，在三个领域呈现出三种形态——coding 是量变、生物医学是"能力变强但知识没变、限制变多"、机器人是质变但速度锁死。后面两章分别展开机器人的架构出路和制药的验证出路。

### 第七章：分层架构之辩（31:40 - 35:25）
机器人的经典架构是分层：上层 VLM（视觉语言模型）做任务规划（"我要吃西红柿炒蛋"→打开冰箱、拿西红柿、拿鸡蛋），下层小模型做动作执行（冰箱门到底怎么开）。许华哲解释说分层本身没有争议，**争议在"这一刀切在哪"**。

Astra 带来的变化是它把边界**往下压**了：以前上层模型只能下"打开冰箱门"这种语义级指令，现在 Astra 能直接下"把手往右伸两厘米""把手放在门把手上，没抓住就再往前靠一靠"这种低层次动作控制指令——下层于是退化成近乎反射式的执行（"能听懂往左往右，像提线木偶"）。这就引出激进派的问题：上层能不能无限下压，最后变成完全端到端、Astra 直接控制一切？

许华哲反对，理由有二且都有实测支撑。第一是**速度**：网上所有 Astra 做控制的视频都是 16 倍速或 24 倍速播放的，原速"基本就是在那纯等待"。第二是**直觉物理缺失**：人碰一个杯子，直觉知道有水会洒、玻璃会碎；Astra 经过很多语言推理能理解，但无法在任务中即时反应，这块需要世界模型或快速模型补位。关于"为什么慢"，他的分析很精彩：模型大是一方面，更关键的是 CoT 太长——Astra 的思维链是加密的（展示出来的 CoT 是假的），但内部推理非常冗余，且**复杂任务和简单任务的思考时长基本相同**，简单任务上纯属性能开销，"看起来非常笨"。泓君笑评：内耗型人格。

### 第八章：原生机器人模型的活路（35:25 - 39:10）
既然 Astra 能压到低层控制，那破壳机器人这类做"机器人大脑"的公司还有活路吗？许华哲用自家招牌 demo——筷子夹小球——做了直接对比。自家模型快得多，抓取时连续不断尝试，失败后凭状态变化换角度再试，中间没有逻辑思考；Astra 则每做一步都要分析"为什么会这样、我该做什么调整"，更像人类思考过程，但一是缓慢，二是**容易陷入僵局**——一旦分析出错就推进不下去。另一个短板是旋转类操作（抓起东西再塞进墙上小孔）要反复尝试，仍是弱项。

对行业格局他给出三个判断：其一，"Astra 让仿真复活"是 hype——Real-to-Sim 只是把 3D 外观做得很好，物理引擎并没有变得更准确，所以他始终坚持仿真训不出最好的机器人策略；其二，**Astra 利好本体/硬件公司**——斯坦福某课题组把 Astra 接进宇树机器人做家庭任务，论文大约两周就做出来了，说明本体质量够好就能直接连 Astra 干部分活（虽然只是 demo 级）；其三，大脑公司会分化成两派：一派继续训更快更强的具身模型（可以从 Astra 学数据标注方式和 CoT 方式），另一派干脆放弃自训模型、转型做"Astra 的工具供应商和部署商"。

对研究领域的影响也有两层：训模型的人不会再忽略 Astra 这个范式；而传统机器人规划领域（TAMP，任务与运动规划）——过去用"拧瓶盖前必须先确认瓶盖是关着的"这类刻板顺序逻辑，已被认为过时——在 agentic 时代重新焕发生机。整个领域的钟摆从"规划"摆到"模型"，现在又摆回"规划"。

### 第九章：范式与数据标注：生肉与熟肉（39:10 - 42:20）
泓君追问许华哲"从 Astra 身上学到了什么"，他的答案是**因果标注**：过去的机器人数据只标注"做了什么"（正向一句话描述），没有标注"为什么成功/失败"——没抓住它，是因为抓的位置偏上了，还是东西沾水太滑？把交互过程中的因果和直觉物理详细标出来，才能真正训出通用机器人大脑。Astra 展现的能力暗示 OpenAI 内部用的就是这类标注。

这直接引出数据标注行业的分层。传言 **OpenAI 现在只买不标注的数据**——认为外面的标注都是错的，全部内部重标（同时也是保密标注方式）。于是数据公司分成两种生意：卖"生肉"（生数据，像卖石油，靠起量，管理一千一万人采集或把所有家庭环境 map 一遍）；卖"熟肉"（熟数据）——需要了解最前沿模型怎么训练，能自信地说"这是 OpenAI 的标注方式，这是 π（Physical Intelligence）的标注方式，你选哪个"，单价可以翻 10 倍以上。泓君感慨"这水还挺深的"，Bill 补刀：熟肉商还得在交易中通过局部观察反推各家模型公司怎么用数据——"也是一个 CoT，推理对方"。这章把 Astra 的影响从模型层延伸到了数据供应链，也为第十二章制药数据金矿的讨论做了预演。

### 第十章：GPT 时刻的成色检验（42:20 - 47:10）
这章是许华哲的心理变化史，也是对"机器人 GPT 时刻"最诚实的一次校准。时间线三段：刚上手时惊艳（抓取→空间旋转→复杂语义逐步测试，觉得"机器人的 GPT 时刻还是 GPT"）；深入后看到问题清单；现在转向技术整合思路。

问题清单有三条硬的：**双臂任务几乎没法做**，叠衣服 Astra 完全叠不了——结论是在"语言不好描述的任务"上 Astra 能力并不强，灵巧操作仍有大空间。**总结能力差**：第一次做一件事花 1 小时，第二次 45 分钟，之后永远 45 分钟——从第三次起耗时变成常数，不像人或充分训练的小模型那样越做越快（人随手干一件事几秒完成）。**旋转操作反复尝试**（前章已述）。另外 Jev 在机器人上表现很差：它不能输入图像，必须先跑视觉模型转成状态再喂给它；摞方块经常摞不起来或倒了， lacks Astra 那种"第一块摞歪了第二块反向找平衡"的直觉。但 Jev 可能适合标数据（快），且 OpenAI 即将发布带多模态输入的快系统——快慢系统的军备竞赛刚刚开始。

结论："它对整个机器人领域的影响肯定是正向的……相当于一个新的思路，照亮了很多我们之前没有看到的地方。"但既然它已经出现，就不能回避；它自己又有很多问题，不能直接用——所以下一个问题是：怎么把机器人公司擅长的东西和 Astra 结合起来，做出真正通用的机器人。这为结尾他"18 个月后（2028 年初）通用机器人真正实用"的激进预测埋下伏笔。
### 第十一章：AI 制药的湿实验瓶颈（47:10 - 54:20）
进入王晟的主场。他先确认 Astra 在 AI for Science 上比 Fable 5 更强（长程任务能力），随即给出全片最有解释力的一个框架：**干实验 vs 湿实验**。干实验指所有预测和分析都在计算机里完成（CPU/GPU 模拟）；湿实验指在真实实验室里用试管、培养皿对老鼠和细胞做操作。两者的鸿沟就是 AI 制药的核心瓶颈。

逻辑推演层层递进：第一，真正重要的问题**无法被 benchmark 衡量**——存在一个悖论：如果"开发治疗癌症的药物"这个问题我知道答案，那它就不需要研究了；所以我们在意的每个问题都没有答案，最后都必须靠湿实验验证。第二，AI 现在能做到的（生成一个分子式）恰恰是不值钱的部分，因为世界上有很多分子式数据；值钱的部分——这个分子怎么合成、怎么储存、以什么周期给老鼠用药——AI 做得非常差。他给"AI 设计实验"的完成度打分：**只有 30% 左右**，其余全靠人类专家修改。而且设计高效实验需要的不是教授级知识，是专门做过千百次实验的 technician 的手感；AI 还不能根据每个实验室不同的器材设备针对性设计——他的比喻：饭店里有番茄鸡蛋土豆，让 Astra 做道菜，它不会就地取材，而是给你设计一个海鲜大餐。

第三，**验证周期与模型迭代速度的赛跑**：细胞和老鼠实验几周能做完，但灵长类（猴子）实验一个周期 4 个月，做两次就是 8 个月；AI 制药公司一般做到猴子实验结束就把候选药 license 给大药厂做人体实验（授权费一般 1000 万美元起），整体周期 6-12 个月。问题在于：这几周里模型可能已经进化到 GPT-6.1、6.2 了——"到时候 AI 模型都进化得比我这些真实实验要更快"。这解释了为什么 AI 能攻克千禧年数学难题（可验证、不需要实验）却没有一款被验证的 AI 药物：**现实世界的反馈太慢，且受限于自然规律**——老鼠和猴子的新陈代谢就是需要那么久。上一波 AlphaFold 时期（AlphaFold 1/2 刚出来时）雨后春笋般冒出的 AI 药物发现公司大部分没成功，正是因为把设计分子式的周期从半年压到几小时，最后还是被真实实验卡住。他的解法不是等，而是**改造实验室本身**：把前置条件全部备好，AI 预测一出来立即把小分子放进去，把湿实验和 AI 模型当成一个闭环来设计，而不是 AI 设计完移交合作者再单独设计一套实验。

### 第十二章：数据金矿与湿实验军备赛（54:20 - 61:00）
如果说上一章讲"为什么慢"，这章讲"慢本身造就了什么生意"。AlphaFold 3 把研究和数据全部开源（社区还有 OpenFold 等复刻版），效果类似 π 开源之于机器人——底层基础设施 ready 了。但王晟的关键观察是反直觉的：**开源之后，垂直科学 AI 公司反而更具备优势**，因为护城河从模型变成了数据。一条数据的定义：一个完整的实验在动物身上跑通——比如一个分子在老鼠身上到底能不能杀掉癌细胞。这样的数据值**几万到几十万美金**（实验成本高+周期长），而且是互联网预训练语料库里根本看不到的。

由此推演出生意模式：模型负责给想法，实验室专门负责验证——这会是个很好的商业模式。类比已经发生的事：一道奥数题的数据卖几千美金，Terminal-Bench 一题几千美金，新出的 Terminal-Bench Science 一题也是高价，而这些"仅限于计算机里的操作"；真实生物世界的数据价值只会更高。更值钱的是**帮 AI 方便做真实实验的接口**：瑞士公司 Adaptyv Bio 与 Anthropic 合作，Anthropic 生成预测，它以 MCP（模型上下文协议）形式立即开做实验，刚融资 4000 万美元。王晟预测以后每个湿实验公司都会以 MCP/API 形式直连大模型，砍掉人际沟通成本。

前沿 lab 的军备布局：Anthropic 明确自建湿实验团队（招的人都有湿实验背景），并办了一个蛋白质设计比赛，以 Adaptyv Bio 的湿实验验证为最终评判标准；与哈萨比斯同获诺奖的 John Jumper（节目中称"江珀"）已加入 Anthropic，另一位同奖得主 David Baker 创办了 Xaira 等几十家公司。DeepMind 路线则是 Isomorphic Labs 端到端。趋势判断：**前沿实验室如果真想做高价值发现而不是刷 benchmark，不可避免要有自己的湿实验室。**

### 第十三章：超越最强科学家之后（61:00 - 67:50）
这章讨论一个微妙的问题：当 AI 在定义良好的问题上已经比顶尖科学家强，人类科学家的角色是什么？王晟的自白很有分量：Terminal-Bench Science 上的生物医学题，他亲自去试，"我做得都没有 AI 好"——Astra 只有六十几分（满分 100），但已经超过了他。他据此宣布"生物医学的干实验 coding 任务已经可以认为解决了"——虽然 benchmark 没到满分，但已经比人强。

但他的结论不是悲观的，而是角色迁移：**人类从解决问题转向定义问题**——设计 benchmark、设计 evaluation、定义哪些问题值得 AI 去解。未来生物医学 benchmark 的设计原则：没有上限、不可能被刷爆——比如现在 SOTA 药物能杀 30% 癌细胞，让 AI 持续设计能杀 40%、50% 的药物，做的过程中形成数据飞轮（湿实验虽贵虽慢，持续做还是能积累可观数据）；要避免"这个基因是否致癌"这类容易被刷爆的简单分类任务。此外还有一层社会性：制药和治疗直接与人打交道，需要人类科学家背书——"就像飞机就算能自己飞，我们也希望有个驾驶员在上面"。

关于"AI 还没有一款自己发现并验证的药"，他判断纯粹是时间问题：AI 是新时代的东西，而一个药的周期要 5-10 年，时钟还没走完；今天那些号称"AI 高强度参与设计"的药，研发启动都在 5-10 年前，"那时候的 AI 和现在完全不是同一种 AI"，更多是噱头。突破的分布规律：**进展几乎正比于实验周期**——周期越短反馈越快的领域（酶、蛋白质设计）迭代越快，Anthropic 的酶设计比赛就选了实验特别快的领域；而衰老、罕见病这类长周期问题，模型进展会很慢。理论上蛋白质是万能的（减肥、癌症都可通过蛋白质制药干预），酶则更多是工业催化剂（地沟油变食用油、洗衣粉不同温度保持活性），商业价值大且能快速落地。

### 第十四章：蒸馏的价值与从零学习（67:50 - 71:51）
泓君转述前沿研究员的一个"悲哀"观察：普通人可能连被蒸馏的价值都没有了——训练信号正在转向专家数据和可验证环境。三位嘉宾各自从本领域反驳或补充，这章是全片思想密度最高的部分之一。

许华哲（机器人）：**"机器人这每个人都是生活的专家……大家都值得被蒸馏。"** 你擅长做饭、我擅长叠衣服、他擅长跳舞，家常菜水平就够。今天机器人还做不了"大模型之于普通人档次"的事，也许一两年后才轮到"必须是 Gordon Ramsay 这样的大厨才值得被蒸馏"。王晟（科学）：单科学家知识量比不过 AI，但长期投入需要人背书；而且存在**反向蒸馏**——他天天在蒸馏 AI，交叉学科的新领域快速向 AI 学习后，自己出成果更快，"这是一个互相蒸馏的过程"；医学领域人还有永恒的角色：定义问题（"想活到 200 岁、500 岁"这类需求源源不断）。Bill（模型）：现在的大模型是靠 memorize 死记硬背+训练中硬灌 know-how，在固定场景上大量 overfit（过拟合）——**"其实目前我们 overfit 的领域可能都还不够"**，还远没到真正的 general intelligence。真正的下一步是跳出"蒸馏/overfit 每个场景"，去模拟**一个人从零开始学习**的状态：蒸馏的不是"人能做好这件事"，而是"人是怎么学的"——一个 underfit（欠拟合）的基础模型，能不能在一个月交互内达到人类基础医生水平、三个月达到教授水平，全靠自我迭代。这块人类还远没有被取代，而且"很多是表层技能，不是底层思维方式"。

### 第十五章：三人最关心的问题与 2028 预测（71:51 - 78:03）
收尾阶段每人给出自己领域最关心的问题，等于三份"未来 18 个月路线图"。

Bill：**算力下沉**。全世界内存（RAM/VRAM）有限且贵，大家担心数据全上云；他的愿景是算力铺开——每个人、每家公司都有自己的算力跑自己的模型（不必最大），解决生活 80-90% 的问题。他同时回应了"模型会不会一直变大"：会，但有广度和高度之分——AI for Science 需要高度很高的模型，日常生活和企业工作需要广度大但尺寸不必大的模型，正确组合可以缓解硬件和电力瓶颈。

王晟：**AI 对真实世界的理解与资源调度**。科学本质是研究真实世界（物理研究宇宙、生物研究生命、化学研究微观），AI 需要的不只是解题，而是"知道我实验室有哪些资源，该让机器人或人做什么"。他构想了一个范式反转：现在是人写 prompt 指挥 AI，未来是 **AI 来 prompt 真实世界**——生成清晰、可执行、无歧义的指令，人和机器人照着调动现实资源。他甚至设想改造仪器本身：现在拍 X 光/CT 还要合成图片给人类医生看，未来直接把底层波形信号给 AI 看，跳过生成图片那一步。判断 AI 的标准也会从 instruction following（指令遵循）变成 instruction generation（指令生成）。他给的具体例子：不是"给我设计个治癌药物"，而是"给你 10 万美金、老鼠实验一次 2000 美元、人体实验周期这样，给我设计个药物"——AI 能真正规划真实世界里的复杂任务。

许华哲：**零样本泛化**。机器人曾有两条正交的路：部署（AI 赋能上一代机器人，工厂开环拧螺丝变闭环，但"还是有点逆时代"——需要 5 个博士在工厂睡 3 个月调稳定性）vs 泛化。他要的是 5 个普通人就能完成的零样本部署，宁可接受一定冗余。他的时间表：**2028 年初**（约 18 个月后）通用机器人开始真正实用，家里可以用语言让机器人做 90% 的事——泓君说这预测相当激进，他回"如果你玩了 Astra、下个月玩我们的模型，应该觉得比较合理"，并强调机器人其实已比大模型慢了一倍，物理世界总归要慢一点。

### 第十六章：尾声：能力曲线 vs 落地周期（78:03 - 80:00）
泓君的收尾独白把全片拧成一个概念：上周办 Alignment 2026 大会时她问王晟，Claude 找到类 CRISPR 新酶系统（ART）这事，AI 圈和生物圈反应有什么不同？答案：**AI 圈非常兴奋——AI 开始做科学发现了；生物圈反应平淡——想在实验室里验证了再说。** 两个圈看的是两条曲线：AI 圈看能力曲线，行业里的人看落地周期。模型层的进展和一个行业真正的改变之间，隔着的不仅是智能，还有验证——机器人要在真实世界里反复试，制药要等猴子和老鼠的新陈代谢，agent 要过商家和用户那一关。这个框架解释了全片三位嘉宾的所有"冷静"：他们不是不认可 Astra，而是各自领域的那条落地周期曲线，走得比能力曲线慢得多。这就是本期节目自称"最接近本质、不容易过时"的部分。
