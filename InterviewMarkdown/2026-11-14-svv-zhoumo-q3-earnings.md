## 分章详解

### 1. 两轮暴跌的本质区别：从供给担忧转向需求担忧（00:00–02:52）

节目冷开场直接给结论：Q3 财报公布后，美股科技股再遭一轮抛售，整条 AI 供应链集体下跌。周默把秋季这轮与夏季那轮做了结构化区分——**夏季跌的是「预期」，秋季跌的是「数据」**。

夏季暴跌时，模型公司的 ARR（年度经常性收入，订阅/API 收入的年化口径）并不透明，市场反而倾向于往好处想：当时大量声音预期「七、八月 ARR 说不定能接近 800 亿美元」。也就是说，夏季那轮下跌是在信息真空里跌的，跌完还有想象空间。而这一轮的导火索是 Anthropic 与 OpenAI 的 ARR 实际数字让人失望——周默口径：Anthropic Q3 ARR 只有约 700 亿美元，低于预期，且季调后 ARR 增速在放缓。

这一区分的推论很重要：**担忧的焦点从供给端（算力不够、产能瓶颈）切换到了需求端（模型收入增长本身）**。正因为这季数据透明度比上季高，「过度乐观」的容错空间消失了——往后只能逐月跟踪两家实验室的 ARR 与收入表现。这也是全场的定调：标题里的「验证期」即由此而来。

（注：ARR 700 亿/800 亿为口播口径，与 S-1 披露的 H1'26 收入 $162.9 亿轨迹相比明显偏高，run-rate 口径存疑，详见事实核查表。）

### 2. 前沿模型格局：双寡头变成「4+1」，开源差距先缩后阔（02:52–07:24）

主播引用周默机构几天前更新的报告：前沿模型格局已从 OpenAI+Anthropic 双寡头变成「4+1」，其他人快速追赶。周默从训练范式切入解释这个格局怎么来的：当前前沿训练高度聚焦 RL（强化学习）最大化——各家都在围绕各领域的 benchmark 找数据、优化、再把效果合并回去，本质是**流水线式训练**。谁流水线跑得顺、算力够，谁就领先。

- **Google**：状态比上季改善，主因是 Gemini 团队重组后能把精力集中到这条 RL 流水线上（此前大量精力花在偏科研突破、冲诺奖级成果的方向上）。周默提醒一个反常识事实：Google 算力其实是劣势——别家可能有 2GW 时 Google 只有约一半，因为大量 TPU 要留给自家产品与伙伴。但训练流程几乎全自研，做到 4.6/4.7 之后通往 5.0 的路很清晰，「没什么惊喜，只是时间和算力问题」。
- **Meta**：算力优势极强 + 极重视 RL 数据准备，追赶路径清晰。
- **xAI**（字幕乱拼为 Space）：算力甚至超过 Google，且有高质量数据源和漂亮的收购。

开源 vs 闭源是这段最有信息量的部分：今年 7–8 月时开源与闭源的差距曾从预期的 6–9 个月缩到 3 个月，震惊业内；但**过去一个季度差距重新拉大**，原因是闭源方收紧了 API：其一，「合成 API」蒸馏迁移（大模型带小模型学指令遵循）从 9 月起被封禁；其二，闭源模型开始用 loop transformer（循环变换器架构），开源方只能靠猜实现方式去复现，猜的过程往往步骤比原版更多，导致推理效率反而更差——能力接近但 token 消耗更高。结论：开源逼近的速度被人为按了暂停键。

### 3. 价格战、企业 routing 与「企业级闭源」新打法（07:24–12:57)

过去两三个月前沿模型连续降价，中小规模闭源模型的性价比已经追上开源。周默团队近三个月调研了近百个国家的企业 AI 使用情况（样本约 100 家全球企业，滚动跟踪），发现两个真金白银的shift：

**其一，企业开始认真用 routing（路由）**：复杂任务发给前沿大模型、简单任务发给开源/小模型。上季度很多企业还只敢把 5–10% 的 token 预算给开源和小模型，随着路由普及，现在预期给到 **20–25%**。routing 大规模采用才一两个季度，比例还会涨——从终端 token 预算看，开源份额确实在扩大。

**其二，闭源模型的应对是「退守企业级」**：公开 API 会被蒸馏学习，那就把最强模型只放在企业渠道——KYC（了解你的客户）做得好、数据爬不走。典型如安全与生物类模型，已不再公开发布，直接供给垂直行业大客户（这些行业里大客户预算占绝对大头）。周默预判：未来会有更多行业出现「企业版模型能力 > 消费者/普通 API 可得模型」的分层，这是闭源维持行业优势的核心策略。

对「开源模型创造的算力需求是否被低估」的追问，周默的回答是：只看前沿模型确实会低估（还有 Gemini、企业自部署等），但目前低估不多——极端企业也就 1/4 预算给开源。真正的边际变化在 **AI 原生创业公司**：过去它们必须全押前沿模型（产品体验不能输），但成本敏感场景（典型如个人助理/personal agent）正在开始改用开源和优化模型，这是「AI 创业公司开始尝试开源」的观察拐点。

### 4. Anthropic S-1 颠覆估值逻辑：容量叙事作废，RPO 锚缺失（12:57–19:08）

本访谈的核心章节。背景：Anthropic IPO 在即，市场拿放大镜看它的 ARR 与增速；S-1 招股书披露约 70% 算力用于训练/研究下一代模型，仅 30% 用于付费推理（主播引述），周默据此推演这如何颠覆华尔街的估值方法论。

**第一层：容量定增长的旧公式死了。** 2026 年 10 月前，卖方预测 LLM 明年收入的通行方法是「容量法」：假设产能极度紧张、推理收入受算力约束 → 估算明年能锁多少数据中心容量 → 按每 GW 收入切分推理/训练 → 推出收入。因为大家都对数据中心容量很激进、每 GW 收入变化不大，这个方法显得「相对确定」，推出的增速自然很快。但 S-1 数据反过来：**如果真是容量约束，推理算力占总算力的比例应该逐季上升**（把更多产能分给推理才对）；而 Anthropic Q3 财报里推理算力占比过去每季都在涨，这季第一次下降。再看它明年更激进的算力承诺（口播：简单假设年底达到 1500–1600 亿），推理占比还会更低。所以「推理容量限制公司增长」的论断不再成立，**用容量预测明年 ARR 的整套逻辑被削弱**——而替代锚还没建立。

**第二层：找不到可比对象。** 周默给出的估值三要素：增长确定性、可比商业模式、利润率扩张确定性。现在第一项就存疑，第二项也拧巴：对标 Palantir（约 20x P/S）？对标上市时 100x P/S 的 Snowflake？都不像。如果硬按 SaaS 逻辑看明年收入，第一个该看 RPO（剩余履约义务，已签约未交付收入的权威口径）——但 Anthropic 的 RPO 只有约 100 亿美元，对比 ARR 就是「零头」（复算：若 ARR=800 亿，RPO/ARR≈12.5%；Snowflake 同口径约 50%，CSP 的 backlog 也是靠多年期合同堆起来的）。没有 RPO 支撑明年收入假设，卖方被迫逐月跟踪，可见度反而下降。周默替 Anthropic 找的解释：它当前销售并不主推多年期合同、以 API 为主——若逼客户签长约，RPO 比例当然能上去，但那是另一个商业模式。

**第三层：$750B 算力承诺锁死利润率弹性。** 嘉宾引用周默机构口径：Anthropic 已做出约 7500 亿美元的长期算力承诺（口播），考虑到公司对 AGI 的信仰（很多研究员预期 2028 AGI），这个承诺大概率不会撤。于是收入增速直接决定利润率：增长快利润率改善、增长慢就恶化。Q2/Q3 毛利率虽稳，但训练成本占收入比在上升——**明年利润率大概率比今年略差**。结论：估值变成「精细的艺术平衡」——你叙事比软件公司性感（解决人类生存问题），但明年收入看不清时，想象力很难给足。

（核查注：真实世界锚点——Anthropic 2026-10-26 递交 S-1，代码 ANT；11/10 启动路演：发行 8.25 亿股、每股 $70–78、上限募资 $643.5 亿、完全稀释估值最高 $1.405 万亿、11/19 纳斯达克上市、AMD/NVIDIA/微软/谷歌等七巨头 $260 亿战略配售。H1'26 收入 $162.86 亿、Q2 首次经营利润。）

### 5. 前沿实验室的成本死结：80% 收入来自新模型（19:08–21:29）

主播追问盈利前景，周默给出前沿实验室商业模式最残酷的一条：**80% 的收入来自最新发布的模型**——新模型一出，旧模型经济寿命迅速衰减。客户主要是科技公司和创业公司，迁移成本不高，说走就走。要维持收入就得持续投边际成本，且这些成本停不下来（算力承诺是刚性的）。唯一的解法是显著加快训练节奏、持续拉开与对手差距——这正是 METR 类报告（评估 AI 加速 AI 研发的迭代速度）被全行业盯住的原因：如果 AI 能加速自身的模型迭代，边际成本曲线才能压下来。但周默认为明年之内未必看得到明确变化。

### 6. ARR 之外的 AI 市场：开源收入藏在 CSP 报表里（21:29–24:34)

「双雄 ARR 是不是 AI 全行业的好指标？」周默：是收入的好指标，但有口径盲区。**开源模型的 ARR 根本不出现在开源厂商报表里**——它埋在 CSP 的收入、GPU 租赁收入里。按常识估计，闭源/开源收入比约 80/20（现在可能更极端、90/10），但因为开源模型毛利更低（SaaS 毛利 80%+，开源只有 20–70%），算力成本比可能是 1:1 甚至 3:2——**收入小并不意味着吃掉的算力少**。

第二类盲区：不符合传统企业 IT 画像的客户——金融（量化基金自建算力/内存甚至供应链，因为 ROI 好算且今年赚翻了，金融是 coding 之外硬件 CapEx 增速最快的行业）、Bio、机器人（周默机构一个多月前发布机器人采购预算报告，数据训练预算出现明确拐点；这些公司在激进锁定新云算力，但 AI ROI 今年甚至明年都看不到）。所以看算力需求，双雄 ARR 会低估；看收入，OpenAI+Anthropic 已经是较好的代理指标。

### 7. Personal Agent 大算账：十亿用户叙事 vs 每月 $30–60 推理成本（24:34–29:02）

coding 之后下一个能撑起主收入流的场景是什么？周默认为 Q3 最大变化是 Personal Agent 叙事兴起（10 月整个 AI 板块表现好、硅谷久违地为一个消费级产品兴奋——Inflection 等好公司、MES 等创新产品出现后，市场开始想象「十亿用户产品」：全球工程师约 3000–4000 万人，十亿用户=30 倍于工程师人群的规模）。

但他立刻泼冷水，给出本场最实用的一段算术：**Personal Agent 每 DAU 每月推理成本 $30–60**，天然限制用户规模。拿 Meta 算账：北美约 2 亿+ DAU、每用户现有广告等产品月贡献约 $50。Personal Agent 的变现路径：订阅费 $20/月 × 付费转化率 20–25%（ChatGPT 口径）≈ 人均 $5/月；广告路径假设 +30% ≈ 每用户多 $10–20。现实情形下单个用户很难立即贡献几十美元，保守按 $15–20 算——**结论：五年维度可以是伟大的市场，但 2027 年只看它会失望**；在保证质量前提下把成本优化到规模可承担，是解锁潜力的前提。AIDD（AI 制药）与机器人同理：瓶颈在临床 II/III 期，明年不可能规模化收入。本场直白判断：「这个季度你找不到一年内能给你同样确信度的千亿级新产品；五年视野有，一年视野没有。」

### 8. 剪刀差与砍单噪音：AI 收入与 CapEx 的缺口仍在扩大（29:02–34:37）

回忆链：半年前（今年 Q1）曾出现 AI 收入与 CapEx 绝对值缺口收窄的好信号，但随后供应链各环节涨价推高 CapEx，缺口重新扩大——**从首次观察到这季，缺口持续扩大**。最直观的读法：看 CSP 报表里训练成本占比上升（Lab 是全链条 CapEx 的领先指标，它的想法决定下游 CSP、服务器厂等每一环）。「用 ROI 论证这季比上季更差，而且越接近 AGI 越难论证——你要往训练里灌更多算力。」这一趋势大概率延续到明年。

需求侧拆三层（周默团队近期研究框架）：① AI 创业公司预算——最健康，商业化在加速，但高度依赖融资环境（融到的钱直接烧成 token）；② 大科技公司——用量在放缓（例：Apple 开始限制员工使用、设预算上限）；③ 传统企业——上半年大量采用后进入部署深水区，需要更多时间。第一层好、后两层不确定性在涨。

市场当下在找「预期重设的锚」：上周大量讨论 2028 CapEx 还能不能涨——现在讨论的是 2028 持平、甚至有人在问 2027 下半年环比会不会降。对应到供应链：近两周砍单传闻四起，但周默供应链口径是：**服务器层面（ODM/OEM）还没有大的、明显的变化——没有砍单**；噪音集中在组件层（CPU、光模块的交期变化或技术切换）。他的提醒：一旦开始砍就很难停，这正是市场害怕的，所以对边际噪音高度敏感。

### 9. 入口之战：Anthropic 议价权、TPU 黑箱与 API 回流 CSP 渠道（34:37–37:53)

延续上期「模型正在取代云成为入口」的话题。证据一：**Anthropic 与 AWS/GCP 重新谈成了租约价格**（尤其 TPU 与 GPU），这就是它 Q3 毛利率好于预期的来源——相对 CSP，模型公司的议价权仍在。而且这直接影响了 AWS/GCP 本季增速（两家都略低于市场预期）。

证据二，TPU 的收入弹性黑箱：CSP（尤其 AWS/GCP）的收入增长现在高度依赖 TPU 卖了多少——**多卖 10 万片，GCP 增速能摆动 10 个百分点以上**；传统云业务增速波动通常只有约 3%。卖 20 万片还是 30 万片，完全两个世界。GCP 增长史上从未见过单一公司有这样的收入弹性，AWS 同理。（机制解释在 §11：卖断=一次性确认五年收入，出租=五年摊销，短期收入差巨大。）

证据三，API 渠道回流：更多 API 销售转向传统企业客户，而传统企业最在意安全与 SLA，**宁肯从 CSP 买模型 API 也不要直连模型公司**——于是 Anthropic 经 CSP 分销的 API 占比在升，且会持续到下季。增量视角：本季 ARR 增速虽不快，但增量大头来自 Amazon 渠道，远超其披露的 48% CSP 收入占比。入口之战这季的记分牌：模型公司靠重谈租约赢回一城，但企业渠道的入口正在向 CSP 倾斜。

### 10. 微软：四家里最干净的一份财报（37:53–46:43）

主播给底：本季总营收 $923 亿、+19%（注：口播 $62B 为字幕量级错误，真实 $92.3B；「超指引 48%」系 Azure +48% 的误译混入），Azure +48%、下季指引 48–50%（仍在加速），FCF $186 亿（口播 $18.6B ✓，为四家中唯一明显为正），季内还发行了 $25B 债券。周默评价：「非常干净，没什么可挑剔的。」财报前他们最放心的就是微软。

框架：看微软就看两件事——**Copilot（决定长期叙事与估值）+ Azure（短期收入主引擎）**。

Copilot 三个积极信号：① 席位结构质变——上季开始大跨国客户从几百/几千席位跳到数万席位；买 5–10% 席位是试点，买超 50% 是大规模铺开、当刚需用，这季更多大客户越过该门槛。② **交付周期差出 3–4 周**：渠道调研显示，企业对比「Office Copilot vs 实验室企业级 agent」时，Copilot 的交付周期约快一半——因为它天然对齐企业已有的身份/安全/权限体系；用 OpenAI/Anthropic 的企业级产品反而要微软 Office 团队配合改权限配置（微软自己产能也紧、且你在要求它配合竞品），各种摩擦叠加成 3–4 周差。今年企业焦虑感强（看到 dev 团队每月烧几千美元、别的部门连 $20 产品都没用上），交付快就是巨大优势。③ 底座模型进步缩窄了产品差距——GPT-5/6/7/8 系列更新让「靠微软重编排优化」的必要性下降，Q1 时用户还在抱怨 Copilot 做的 PPT 丑，到 9–10 月已明显变好。

AWS 侧顺带一笔：本季约 40% 的 AWS 增长由 OpenAI 及相关产品贡献（周默自估口径）；下季 50% 的公司总增速指引中，25 个点来自 OpenAI、25 个点来自非 OpenAI。OpenAI 影响力只增不减，但它签的是长约、承诺比多数客户强——隐患是议价权此消彼长，说不定哪天微软也要像 AWS 那样跟 OpenAI 重谈合同。

Copilot 披露口径变化是本段最精彩的细节：本季起只公布「使用量」不再公布付费席位数。周默拆解这个信号：上季「超 30M」、上上季「超 20M」——「超」字极模糊，23M 也算超 20M，净增未必是 10M。若每季真能加 10M，意味着装机每季 +33%，不可能。且渠道核查显示 Q2 很多 Copilot 是 6–7 月才卖出、计入使用量在 Q3——本季收入加速根本不需要 10M 新席位来解释。所以不报席位=两个信号：**肯定没增长 10M；且无需靠席位数解释加速**。30M 是里程碑才提，过了就换口径。最后给叙事定位：Copilot 成了微软的新身份——「做成 Copilot，你就是两大实验室之外全球最大 AI 应用公司，比当全球第二 GPU 云性感多了」，公司会持续押这个叙事。

### 11. 谷歌：广告灰犀牛 + TPU 一次性确认（46:43–53:49)

主播给底：总营收 $1276 亿 +25%（复算基期 102.1B vs 真实 25Q3 102.3B，✓吻合）、GCP +103%、Search 仅 +12%（广告增速五个季度最慢）、FCF -$91 亿、本季停止回购、发债 $410 亿、财报次日股价 -12.6%。周默：财报前他们最担心的就是谷歌，还专门发了预财报报告，标题即结论——**「第一个被 ChatGPT 冲击的季度」**。

逻辑链：OpenAI 广告收入增长最显著的加速发生在今年 Q3——ARR 从 $1 亿走到 $10 亿就发生在这一季。$1 亿以下没人真正受影响，但 $1 亿→$10 亿足以改变广告主与代理机构的中期预算预期（$10 亿已是显著数字）。季度调研问了一圈代理机构：**所有广告主都说从谷歌挪了份额给 OpenAI，但没动 Meta 的份额**——理由是谷歌预算与 OpenAI 最直接可比。影响尚不大，但「往哪分配」的长期思考已经开始。

谷歌自己的解释是「AI 模式冲击短期变现」，周默拆成两件事：① AI Overviews 的低垂果实摘完了（增加广告位密度 Ad Load 的红利结束，接下来要靠更难的 iOS 表现与 CPM 提升）；② 更根本的是 AI Modes/AI Overviews 与 ChatGPT 冲击本质是同一道题——传统广告业务如何适配新 AI 搜索行为，是被别人革还是自己革。本季已经开始把更多展示分配给 AI 模式，但要证明 AI 模式的 ROAS 更高，一两个季度内拿不出证据。周默定性：**灰犀牛**——AI 冲击广告的讨论迟早要来一个季度，只是恰好落在这季。

第三条坏消息：**Meta 正在蚕食谷歌的强势垂直**。过去一年广告调研从未出现如此方向性分歧（以前结论都是 Meta 好谷歌也好）。Meta 在自己传统弱势领域（旅游、金融）明显逼近谷歌；Meta 财报分地区看，北美广告收入增长 10 个点、其他地区没有——中期选举能解释 4–5 个点，剩下 5–6 个点无解，指向的就是从谷歌手里抢份额。所以谷歌这份财报最大的讨论点不是 AI、不是 GCP 增速——**是广告叙事要不要切回「谷歌广告正被 AI 袭击」**。

GCP 侧的机制课：卖断 TPU vs 出租的会计差——出租 5 年=收入摊销 5 年；卖断=**一个季度一次性确认五年收入**，同样 1 万片，卖断对短期收入提升远大（长期可能不如出租，但短期冲击巨大）。周默算过：10 万片约影响 GCP 增速 12 个点——所以 103% 里到底含多少 TPU 一次性确认是个黑箱；很多人觉得本应到 108–110 才算及格，103% 实际是「符合预期或略 miss」。Gemini 本身 Q3 无重大变化，真实改善要等新模型发布（Q4 才可能有贡献）。

产能侧的反直觉事实：谷歌一边卖 TPU 一边高价租 SpaceX 算力，为什么？——**谷歌算力依然严重受限**：明年 TPU 产量因供应商良率问题从原计划约 1000 万片下修到约 850 万片；需求却比六个月前的预测大增。去年谷歌算力还多于 OpenAI/xAI、可以「大力出奇迹」，今年可能只有两家的一半，训练上再也不能靠蛮力。SpaceX 产能部分给 Gemini、部分支撑 Gemini API/Vertex 等产品线，所以有理由相信 Q4 Gemini 贡献会更乐观。

### 12. 亚马逊：本季 miss，股价反应却最好（53:49–58:38）

主播给底：营收 $2019 亿 +12%（复算基期 180.3B vs 真实 25Q3 180.2B ✓）、AWS +39% 连续六个季度加速、三年期 backlog 扎实（真实值 $578B）、过去一年 FCF 为负、债务翻倍以上。周默：看亚马逊基本只看 AWS——电商别太差就行。

本季 AWS 其实略低于预期（市场预期约 $420–430 亿，实际 $460 亿——注：口播「39 是本季、未来两年 40」为英译混乱，按真实数据 AWS 本季 $46.0B、+39.3%，并未 miss；周默说的 miss 应指增速或分项口径），但财报后**股价反应反而是三家 CSP 里最好的**。原因二：① 给了中期指引，叙事变成「今年稍弱、2028 变好」；② **四大 CSP 里唯一还没募资的**——财报首日市场以为 40（指引口径）意味着马上要融资，后来发现还没发债；「还没」不等于「不会」，但对比 Meta/微软/谷歌都已发债，这是当下最稀缺的姿势。回收周期、加速节奏都没什么可吵的。

本季 AWS 偏弱的两个真实原因：① Trainium 换代青黄不接——Q2 到 Q3 基本是无新产能的空窗期；② 前述 Anthropic 重谈租约价的价格压力。往后看 Trainium 会走 TPU 的路：2027 年底开始对外卖（真实口径：late 2027 外销），需求强、给了中期指引。周默判断：不好不坏，只是市场对融资问题有更多博弈。

关于 Trainium 外销对利润率的影响，周默拿 GCP 做了反例推演：GCP 的 OPM 本来就只有约 30%，卖卡生意的利润率接近 50%，对 GCP 是纯增益；但 AWS 毛利本来就超 60%、OPM 也更好，Trainium 卖断未必能保持 40%+ 的利润率——**对 AWS 利润率大概率无正面贡献，也未必负面，最终可能根本没影响**。竞争关系上目前无冲突：Trainium 主要用户是 Anthropic（Background API 挂在后台，客户根本不知道跑在哪张卡上），远未到 TPU 那种大规模外部客户群的规模。

### 13. Meta：广告最强的一份财报，稀释最贵的一笔账（58:38–66:43）

主播给底：营收 $646 亿 +26%、CapEx $349 亿（占收入 54%，四大最高，复算 54.0% ✓）、CapEx 首次超过经营现金流、Meta AI（M 产品）上线六周破 1000 万用户、财报次日 -7%。真实背景补充：EPS $3.83 超预期 7.28%、含 $9.9B 法律和解金、全年 CapEx 指引上调至 $135–145B。

周默：业绩本身没什么可批评——销售强、广告增长出色、指引扎实。**唯一的污点是花钱**：支出高于所有人预期。市场原本以为每年稀释 2–3%（股权激励增发），现在发现是 4–5%——「如果每年稀释我 4–5%，你不仅没法回购，还在每年稀释所有股东 4–5%」。大公司股东偏好分红与回购（苹果式），长期投资者被这个数字吓到，这是本季股价反应的主因。

广告侧反而是全场最强：① 广告主不会把 Meta 预算挪给 OpenAI（不同预算池），Meta 没有「AI 模式」冲击问题；② **软广（soft ads）CPM 本季跃升**——渠道一致反馈这是 CPM 变化最明显的一个季度，Meta 半年前才开始认真做软广，库存空间巨大、算法明显进步，ad load 还能再加；③ Audience Network（此前不被优先的第三方流量）重启改造，贡献了增量；④ 定点补强对谷歌的弱势垂直：旅游、金融、汽车、B2B、本地服务——这些行业的共同点是**线索（lead）收集不如谷歌**（买车先搜 Tesla Model X vs Y、去墨西哥先搜攻略——意图都留在谷歌），Meta 近半年在算法上显著进步、正在这些领域开新路。周默直言：Meta 本季广告表现与 AI 关系不大，至少现阶段如此。

CapEx 回报怎么验证？Meta 的两条路：出租 GPU（短期难，自家模型团队优先）；以及 Personal Agent 的潜力（下节展开）。

### 14. M 产品留存框架：14 日留存 15–16%，过 20% 才配全量推广（66:43–71:10）

Meta AI（M）的竞争力评估。优势：Meta 的产品方法论——M 是个运营驱动产品（快响应、快迭代、有需求立刻上），不是靠技术突破取胜；触点网络庞大（自有社交网络、可大规模调研、可快速推 广），产品经验与卖点理解深。周默认为**不会有显著技术优势**，胜负手是「本周发现新需求，能否立刻抓住并执行得比对手好」。

增长节奏的冷静判断：财报前 M 约 250–300 万 DAU，现在接近 400 万——**不是推一下就能上千万 DAU 的产品**。Meta 逐国开放、还没做大规模推广，初期推广力度甚至不如 Threads。原因用留存框架讲最清楚：

传统互联网产品上线即定形——首周留存就是最高留存（核心卖点开局就在），社交产品靠网络效应抬留存。但 **Agent 产品开局的核心功能未必是未来的核心**，产品形态还在快速迭代，「你的基线不在了」，必须持续跑数据找满意的过程。对标 OpenAI（乱拼为 OPay）的路径：14 日留存从 10% 起步、花近两年到 20%、现在 25%——到那个水平，14 日留存就可以当长期留存用（潜在用户 × 25% ≈ 长期用户）。**M 现在 14 日留存约 15–16%，此时全量推广=浪费潜在用户**；理想做法是留存过 20% 再推，「过线后一切水到渠成、正循环滚起来」。且留存优化非线性：10%→15% 容易、卡在 17–18% 很常见，所以达标时间高度不确定——不能用「Meta 有 X 亿用户所以 M 应该有 Y 用户」线性外推。

### 15. 融资链与利润上游化：担忧全部集中在新云（71:10–75:50)

循环融资（circular financing）担忧已经存在两三年，周默定性：这类担忧是**闪点式**的——融资规模大到盖不住、或 ROI 缺口暴露、或利率大幅上行引发流动性担忧时集中爆发。当前还有反身性（reflexivity）焦虑：新实验室股价跌→融资更难→更跌的死循环是否存在？

周默的拆法是沿资本链找压力的真实位置：**前沿实验室没有现金流压力**（口播口径：已募 1400 亿+、账上还有 1300 亿、总共才花了约 100 亿、现金流还是正的）；CSP 也不是问题所在（谷歌发债 $410 亿、微软 $250 亿，但主体信用撑得住）。**整个融资问题几乎全在新云（NeoCloud：CoreWeave/Nebius/IREN 这类 AI 算力云商）身上**——零 CapEx 的模型公司把融资与现金压力全部转嫁给新云和 CSP，数据中心是新云建的。市场真正紧张的是看见 NVIDIA 出手背书新云——涨时当利好、跌时读作「是不是不行了才需要兜底」；同一事实两种读法，皆是事后合理化。

放贷方视角的硬核细节：给新云放贷看的核心指标是**净收益 ÷ B**（资产基数）。股价跌不直接改变这个公式，真正改变它的是 **GPU 价格**——GPU 价格一跌，分母缩小、净收益不变、融资压力骤增。股价的间接影响在「相对性」：同一笔钱给 CSP 还是给新云？股价大跌后资金自然倾向 CSP，**暴露出融资链上谁弱谁强**。

上游半导体则在吃走利润：主播给底——TSMC 年内第三次上调全年增速指引（至 44%——注：搜索仅见 4 月上调至「30% 以上」的报道，44% 未见独立信源，⚠️存疑）、ASML 客户已排到 2029–2030 年交付、存储毛利率 80%+、TSMC 毛利率逼近 60%、云厂现金流转负。钱从下游往上游走、利润向瓶颈环节集中。周默框架：一切取决于 CapEx 在上行还是下行周期——上行周期大部分公司都能增长；一旦 flatten，靠涨价逻辑的产品就涨不动了，量大者抢供给、瓶颈随之转移。宏观大趋势同涨同跌，微观上依价格/量结构各有相对变化。

### 16. 中期选举与数据中心审批：影响 2028，不是 2027（75:50–80:29)

2026 中期选举（真实结果：民主党拿下参众两院，并赢得德州等多州州长——CBS 口径）之后，多位新任州长主张推迟/暂停数据中心建设。周默第一句就切割时间线：**影响的是 2028，不是 2027**——2027 年的审批全部照过，新州长已明确。2028 年美国原规划约 60+GW 审批，其中德州约 18GW；若全砍剩 40+GW，市场预期约 15GW 受影响。

但实际冲击大概率远小于纸面数字：① County Judge 周五已表态「不反对所有数据中心，反对的是不考虑德州人需求的项目」，并说明了 SpaceX 项目的可谈判条件——**不是一票否决，是谈判**；② 数据中心需求本质起于市一级——有城市想要、有城市不想要，2028 待审项目很多在红县（以前是达拉斯这类蓝县积极），红县想要税收，逐市逐县自下而上谈判，无法一刀切立法；③ 周默判断受影响规模远小于 18/15GW，更可能落在 5–10GW。

若建设真放缓、供需缺口扩大，**存量算力更值钱**——受益排序：三大云厂（存量在手，且海外产能布局最早：马来/东南亚/北欧，本土受限就切海外）；受挫的是产能集中在美国本土的新云（NuScale、SpaceX 的德州新产能首当其冲，SpaceX 同时是受害者与供给方——太空算力：供应链结论 2028 年约 1GW，有帮助但填不上 10GW 的缺口）。另有一条解法线：自备电源（on-site generation/楼` BTM`）——与县里谈判的两板斧是「给钱（补贴/电价抵扣）」和「证明新增负荷自发自用、不推高当地电价」；100% 自发电是明确的正面信号，社区不在乎技术路线只看结果。

### 17. 软件财报与企业落地：FDE 瓶颈与 $20/$200 决策论（80:29–86:07)

本季软件财报雷多：落地难、安全担忧重（近期安全事件频发），企业反而更信任老牌软件公司加 AI 功能。但瓶颈在 **FDE（Forward Deployed Engineer，前向部署工程师——上门帮你把 AI 用起来的工程师）**：装这些功能产生巨大 FDE 需求，交付周期比预期长。有 FDE 产能的公司本季封神（例：Palo Alto Networks 的 FDE 能力很强）。安全赛道的 TAM 论证方式很「coding 味」：黑客数量是以前的十倍、漏洞数量同倍数放大——**这是软件里第二个能用数字直接论证空间的方向**。受益分化：CrowdStrike、Palo Alto 赢；Fortinet 这类有自己的周期问题。

消费软件意外回温：Upwork（一年前还是软件领头羊话题，随后整整一年没人提、上季市场还看空它丢份额）本季财报反应极好——市场逻辑是想从「AI 受害股」里找「有 AI 竞争优势又不会被灭」的便宜标的，翻来翻去发现消费软件/消费互联网广告生意不是受损目标、还解决了部分竞争问题。聚光灯正移向消费软件。

企业 AI 落地现状（近百家中外企业滚动调研）：**很多企业对方向远没有想象中清楚**——CTO/CIO 不知道该建什么，要靠厂商当顾问给 use case、帮算 ROI。周默的「$20/$200 决策论」：买 $20 的 ChatGPT 订阅不用动脑（别人都买我 also 买，零风险，用量立涨）；买 $200 的产品还要改 AI 工作流——要担责、要想清楚 ROI，决策立刻犹豫。真正方向清晰、ROI 算得精的企业不常见。FDE 越来越像「麦肯锡悖论」：请 10 个麦肯锡顾问能把万人公司毛利提升一个点吗？不能——你请他们主要是**让他们说你想说的话、替你担责**。FDE 与服务公司成为明确瓶颈，节奏放缓不可避免：期望企业一年内花更大预算重构工作流不现实（Copilot 光试点就花了一两年）。

### 18. 收尾三大关注点：IPO 定价、200x P/S 与跷跷板（86:07–91:01)

**第一，Anthropic IPO 是最重要的事件**——它如何框定收入展望与长期承诺，直接给全行业定价。但真正的风险不在 Anthropic/OpenAI，在**新实验室（NeoLAB，字幕乱拼 NewLAAB）**：部分公司估值已到数百亿美元、收入却极少——Palantir 争论的是 20x P/S 合不合理，新实验室要问的是 **200x、2000x P/S 是否有意义**。它们对融资环境高度敏感，效率未必比老牌厂商高，却吃掉新云约 20% 的增量产能——是整条融资链上最敏感的环节与领先指标，甚至可能成为「风暴中心」。

**第二，供应链噪音的辨别纪律**：近两周行业噪音极多，但大概率不会传导到 ODM/OEM，多半只是技术切换。下跌期人们放大每一个声音、叙事互相矛盾——从 A 听到一个、从 B 听到另一个、B 展望更差就得出「砍单」结论，但两者的基准可能根本不可比。**当下听到的很多 FOMO 叙事都来自不可比的比较**，必须逐一验证是否真有变化。

**第三，双雄 ARR 减速的真因不是开源，是价格战**：开源与闭源差距近三个月实际在拉大，ARR 减速锅不在开源。根本原因是 OpenAI 与 Anthropic 过去几个月的价格竞争——OpenAI 先降价+大量送免费额度，GPT-4.5 定价比 4 代便宜 20%（可以说推理效率更高、性价比更好，但定价结构的影响是实打实的）。定价结构一变，就成了短期最大变量。两家 ARR 增速呈**跷跷板效应**——跷跷板出现=竞争对增长的影响大于需求本身。这个视角比盯开源/闭源份额重要：**你以为的开源份额转移，很多其实只是闭源降价造成的口径幻觉**。往后盯价格战会不会稳住。

结尾彩蛋（周默个人观察）：美国版「红果」——短剧在 TIkTok 生态进化极快，但美国的短剧 APP 留存差、要持续买量变现，**本质不是闭环产品**，反而持续给广告平台贡献增量预算、给消费行业输血，是生态正能量；一旦做成闭环（时长+留存起来、自成生态），就会变成抢份额的零和游戏——这是明年可能冲击互联网与消费生态的变量，程度难料。
